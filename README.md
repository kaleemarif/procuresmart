# ProcureSmart

### Sahi Jankari, Sahi Samay

An intelligent farmer procurement guidance platform built for **Smart India Hackathon 2026 — SIH26032**.

## 🎯 Core Idea

ProcureSmart helps farmers decide:

**WHERE to go and WHEN to go.**

It combines procurement-centre information, machine-learning-based waiting-time prediction, and deterministic recommendations.

## 👨‍🌾 Farmer Experience

- Guided crop and quantity input
- Nearby procurement-centre discovery
- Waiting-time prediction
- Best centre/time recommendation
- Centre status and queue information
- Map and directions
- Secure Token
- Sahayak chatbot

## 🖥️ Operator Experience

- Live queue management
- Centre and counter status
- Processing-time updates
- Token management
- Operational monitoring

## 🧠 Technology

- Next.js + React + TypeScript
- Tailwind CSS
- FastAPI + Python
- PostgreSQL / Supabase
- Scikit-learn
- Random Forest
- Leaflet + OpenStreetMap

## 🤖 Intelligence Flow

PREDICT → RECOMMEND → INFORM

## ⚠️ Prototype Disclaimer

The initial ML prototype uses synthetic data for demonstration and benchmarking. Its performance metrics must not be interpreted as real-world prediction accuracy.
